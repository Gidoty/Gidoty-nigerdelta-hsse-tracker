## A.4 — README feature count vs. actual implementation status

`README.md` states: *"25 integrated features across 7 categories: REPORT
· MONITOR · CALCULATE · TRACK · GENERATE · HEALTH · DATA."*

The count of 25 is correct — it matches `TOTAL_PARAMETER_COUNT` computed
from `app/src/data/parameters.js` at runtime. But "integrated" is not
uniformly true: each of the 25 entries carries a `status` field of either
`'built'` or `'placeholder'`. A `'placeholder'` entry renders a generic
placeholder panel (`PlaceholderPanel.jsx`), not its real feature.

| Category | Total | `built` | `placeholder` |
| --- | --- | --- | --- |
| REPORT | 2 | 2 | 0 |
| MONITOR | 5 | 3 | 2 (`incident-type-chart`, `severity-distribution`) |
| CALCULATE | 3 | 3 | 0 |
| TRACK | 5 | 1 | 4 (`incident-response-timeline`, `operator-response-timer`, `nosdra-notification-log`, `jiv-status-tracker`) |
| GENERATE | 4 | 4 | 0 |
| HEALTH | 3 | 3 | 0 |
| DATA | 3 | 0 | 3 (`open-data-api`, `corroboration-status`, `evidence-audit-log`) |
| **Total** | **25** | **16** | **9** |

All 16 `built` entries are reachable in the live app: 15 are registered
in `AppShell.jsx`'s `PANEL_COMPONENTS` map (confirmed by cross-checking
every `built` entry's `panel` id against that map's keys — all present),
and the 16th (`submit-new-incident`) is the dedicated `/report` route in
`App.jsx`, not an AppShell panel. None of the 16 "built" entries were
found to be mislabeled as built while actually unreachable.

Separately — not reflected in the `built`/`placeholder` split above, but
relevant to any claim of feature completeness — several source files
still exist in the repository with real, non-trivial content
(`TimelineCard.jsx`, `EscalationStats.jsx`, `EscalationTable.jsx`,
`FoiGenerator.jsx`, `StatsBar.jsx`, `ChartsPanel.jsx`) but are not
imported or rendered from any route or panel. This was already flagged in
`docs/AUTHOR_ACTION_REQUIRED.md` ("General finding — unwired components")
during the prior JEAS audit; it is restated here because it bears
directly on any EMAS claim about which TRACK/MONITOR/DATA features exist
versus ship. These six files correspond to the 9 `placeholder` entries
above (the entries intentionally route to `PlaceholderPanel.jsx` instead
of these files), so the `README.md` "25 integrated features" phrasing
should, for an EMAS submission, be read and (if the manuscript repeats
it) qualified as "25 catalogued features, 16 implemented and reachable,
9 shown as placeholders."
